# QuantumHealth

Static site for QuantumHealth by Dr. Vikas Singh. Pages are generated by
`build/gen.js` into `dist/` from content in `build/`. Run `npm run build`,
`npm run qa` (build + link/asset checks) or `npm run dev` (build + local server).

## Design theme

The whole site is styled from three stylesheets in `public/assets/css/`:

| File | Purpose |
| --- | --- |
| `tokens.css` | **All** design variables — colours, gradients, type, spacing, effects |
| `base.css` | Reset, global background (glow, film grain, vignette), typography, petals, sections, motion |
| `components.css` | Buttons, header, cards, forms, tables, accordion, lightbox, footer |

There are no hard-coded colours outside `tokens.css`.

### Changing the colours

Edit the palette block at the top of `public/assets/css/tokens.css`. Every
surface, text, border, button and overlay references these variables, so the
whole site updates at once. For example:

```css
--gold: #C9A66B;             /* accent gold — buttons, rules, icons        */
--cream: #F3E9DC;            /* main text                                   */
--black: #0A0508;            /* page background                             */
--burgundy-950: #2A0510;     /* deepest burgundy — overlays, drawer         */
--gold-gradient: linear-gradient(135deg, #B08A4E 0%, #E8D3A3 45%, #C9A66B 100%);
```

Semantic aliases (`--bg`, `--text`, `--accent`, `--line`, …) point at the
palette; prefer them in component CSS.

### Swapping the petal photo

The `.petals` backdrop (hero, page banners, CTA band) is built from layered CSS
gradients defined by `--petals-image` in `tokens.css`. To use a photograph
instead, drop the image into `public/assets/img/` (e.g. `petals.jpg`) and
replace the token value with a single `url()`:

```css
--petals-image: url("../img/petals.jpg") center / cover no-repeat;
```

The fade-to-black mask (`--petals-mask`) and the slow drift animation keep
working with the photo. Mobile uses the simpler `--petals-image-mobile` layers;
update or clear that token as well if you swap in a photograph.
