# Quantum Health

Independent educational website about breast enlargement. No clinic, doctor
or treatment service is represented. Pages are generated by `build/gen.js`
into `dist/` using the canonical registry in `build/structure.js` and existing
authored content in `build/content.js`, `build/library.js`, the research source
modules and `content/sections/`.

Run `npm run build`, `npm run qa` (build, links/assets and migration invariants)
or `npm run dev` (build + local server). The approved navigation is Home,
Surgical Breast Enlargement, Non-Surgical Breast Enlargement, Education &
Research, About. Individual topics are linked from category cards.

After changing the redirect registry, run `node build/sync-redirects.js` to
update Vercel's permanent redirects. QA checks that the deployment table agrees
with the registry. The development server also issues HTTP 301 responses;
static HTML redirect stubs support other static hosts.

Additional verification commands:

```text
node build/content-retention-qa.js
node build/browser-migration-qa.js
node build/responsive-qa.js --canonical --standard
```

Browser checks use the existing local `playwright-core` installation and Chrome.
See `docs/website-restructure.md` for the retained routes and consolidation report.
The complete PDF extraction and pre-deletion ZIP backup are kept locally in
`docs/restructure-audit/`; large audit artifacts are excluded from Git.

## Design theme — luxury burgundy, champagne gold, rose-pink

The whole site is styled from three stylesheets in `public/assets/css/`:

| File | Purpose |
| --- | --- |
| `tokens.css` | **All** design variables — colours, gradients, type, spacing, effects |
| `base.css` | Reset, global background (glow, film grain, vignette), typography, petals, sections, motion |
| `components.css` | Buttons, header, hero, cards, forms, tables, accordion, lightbox, footer |

There are no hard-coded colours outside `tokens.css`.

### Palette — burgundy + champagne gold + rose-pink

```
--burgundy        #35000D   deep burgundy — hero, page banners
--burgundy-deep   #510018   wine red — primary wash, CTA bands
--burgundy-darker #1F0307   near-black burgundy for deepest wash
--dark            #100609   page background, deepest text
--rose            #E95C82   rose pink — accents, "Breast Enhancement"
--rose-light      #FF809B   coral pink — primary CTA gradient
--rose-deep       #C8406B   hover / active state
--gold            #D6B875   primary gold — rules, icons, divider lines
--gold-light      #EBD79E   hover / highlight
--gold-dark       #A88A55   deeper gold — emphasis
--ivory           #F6EBDD   warm ivory — main text, headings
--muted           #C6B7B5   warm muted — supporting copy
--border          rgba(214,184,117,.55)  primary gold rule
```

### Changing the colours

Edit the palette block at the top of `public/assets/css/tokens.css`. Every
surface, text, border, button and overlay references these variables, so the
whole site updates at once. Semantic aliases (`--bg`, `--text`, `--accent`,
`--line`, `--ink-strong`, …) point at the palette; prefer them in component CSS.

### Buttons

* `.btn--primary` — rose-pink pill (`.rose-pill` gradient), dark readable text.
  Used for the home evidence guide, CTA band, and primary educational actions.
* `.btn--outline` — fine gold border, warm ivory text, pill shape. Used for the
  home hero "Explore treatments".
* `.btn--ghost` — minimal transparent with a faint ivory border.
* `.btn--header` — compact rose-pink pill used in the site header next to the
  navigation.
* `.btn--sm`, `.btn--lg`, `.btn--block` — sizing modifiers.

### Header & navigation

* Transparent over the hero, fades to dark burgundy on scroll.
* Ivory nav text, rose-pink active state with a thin underline.
* Logo: gold four-petal mark + "Quantum Health" / "Independent patient education".
* Five primary links wrap at desktop widths. A hamburger toggle opens the mobile
  drawer; contact information is also available in the footer.
* Mobile drawer is a full-screen deep-burgundy panel with ivory text and
  rose-pink current-page markers.

### Hero

* `.hero` — full-bleed section, deep-burgundy-to-near-black gradient.
* `.hero__rose` — three layered blurred rose-petal glows (top-left,
  bottom-left, top-right) on top of the gradient petals backdrop.
* `.hero__copy` — eyebrow, large headline ("Breast Enhancement" rendered in
  rose-pink italic via `.accent-rose`), uppercase supporting statement, lead,
  two CTA buttons, medical disclaimer note.
* `.hero__figure` — full-bleed editorial portrait on the right (desktop), with
  a gold hairline frame inset 14 px.
* `.hero__curve` — curved burgundy lower transition with a fine gold edge.
* `.hero--on-hero` — applied to the site header over the hero for a soft
  gradient backdrop.

### Feature strip (below the hero / page banners)

* `.feature-strip` — six benefit chips on desktop (2 / 3 / 6 columns),
  gold-line icons in circular gold-rimmed wells, ivory uppercase labels.
* Vertical hairline dividers between chips on desktop.

### Swapping the petal photo

The `.petals` backdrop (hero, page banners, CTA band) is built from layered CSS
gradients defined by `--petals-image` in `tokens.css`. To use a photograph
instead, drop the image into `public/assets/img/` (e.g. `petals.jpg`) and
replace the token value with a single `url()`:

```css
--petals-image: url("../img/petals.jpg") center / cover no-repeat;
```

The fade-to-black mask (`--petals-mask`) and the slow drift animation keep
working with the photo. Mobile uses the simpler `--petals-image-mobile` layers;
update or clear that token as well if you swap in a photograph.
